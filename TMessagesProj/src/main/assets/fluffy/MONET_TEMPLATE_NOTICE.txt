Monet theme templates
=====================

Files
-----
  monet_light.attheme
  monet_dark.attheme

These two files map Telegram theme colour keys onto Material You palette tokens
(a1_* / a2_* / a3_* accents, n1_* / n2_* neutrals, plus the monetRed* and
monetGreenCall call-button colours). They are resolved at runtime by
org.ushastoe.fluffy.monet.MonetThemeGenerator; they are not valid .attheme
files on their own.

Modifications made for fluffyGram
---------------------------------
  * dropped colour keys this fork's ThemeColors no longer defines
    (chat_attachFileBackground, chat_goDownButtonIcon, dialogCameraIcon, ...)
  * renamed kvoipgroup_overlayAlertMutedByAdmin2 to
    voipgroup_overlayAlertMutedByAdmin2
  * enabled the glass_* keys, which upstream ships commented out with "--",
    and gave them separate light and dark values
  * added keys the upstream template did not cover: avatar_nameInMessage*,
    chat_in/outCodeBackground, chat_in/outQuote, chat_in/outBubbleSelectedOverlay,
    chat_in/outBubbleLocationPlaceholder, code_*, color_cyan,
    chat_wallpaper_gradient_to, stories_circle_live*, pollCreateIcons
  * added the header comment block; lines starting with '#' are ignored
